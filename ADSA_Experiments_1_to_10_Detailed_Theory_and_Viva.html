How to prepare for the external viva

For every experiment, prepare: (1) definition and purpose, (2) working steps, (3) important terms, (4) time and space complexity, (5) advantages, limitations and a practical use case. If asked to compare algorithms, explain the main difference and the conditions under which each works.

Exam tip: State assumptions when discussing complexity or correctness. For example, BST efficiency depends on height; simple subset-sum pruning assumes non-negative values; Dijkstra requires non-negative edge weights.
EXPERIMENT 01

BST Construction and Tree Traversals

Theory and working

A binary tree is a hierarchical structure in which each node has at most two children. A Binary Search Tree (BST) adds an ordering rule: smaller keys go to the left subtree and larger keys go to the right subtree. To construct it, insert the first value as root, then compare each next value while moving left or right until an empty position is found. Traversal means visiting every node in a defined order. Preorder is Root–Left–Right; inorder is Left–Root–Right and gives sorted values in a BST; postorder is Left–Right–Root.

Related concepts to remember

Know these terms: root is the top node; a leaf has no children; a parent has child nodes; a subtree is a node and its descendants; height is the longest downward path. Trees are useful for hierarchical data and searching.

Time and space complexity

Building a BST is usually O(n log n) on average, but O(n²) in the worst case if values arrive in sorted order. Each traversal is O(n) time and O(h) recursive stack space.

Likely external viva questions

What is a BST?

A binary tree that follows a left-smaller, right-larger ordering rule.

Why does inorder sort BST values?

It visits the left subtree before the node and the right subtree after it, matching the BST ordering rule.

Binary tree vs BST?

A binary tree limits children to two; a BST also orders its values.

What is a leaf?

A node with no children.

EXPERIMENT 02

BST Operations: Insert, Delete, Search and Display

Theory and working

A BST supports search, insertion and deletion using its ordering property. Search compares the target with the current node and moves left if smaller or right if larger. Insertion follows the same path until an empty position is found. Deletion has three cases: remove a leaf directly; connect a one-child node's parent to its child; or, for a node with two children, replace it with its inorder successor (smallest value in the right subtree) or predecessor (largest in the left subtree), then delete that replacement from its old location. Inorder traversal is a common way to display the values in sorted order.

Related concepts to remember

An unbalanced BST can become skewed, resembling a linked list. Self-balancing BSTs such as AVL and Red-Black trees keep height small and improve worst-case performance.

Time and space complexity

Search, insert and delete take O(h). They are typically O(log n) in a balanced tree and O(n) in the worst case.

Likely external viva questions

How do you delete a node with two children?

Replace it with the inorder successor or predecessor, then remove that replacement node.

What is a skewed BST?

A tree where nodes mostly have one child, producing height close to n.

How can BST performance improve?

Use a self-balancing BST such as AVL or Red-Black Tree.

EXPERIMENT 03

Minimum Spanning Tree: Prim's and Kruskal's Algorithms

Theory and working

A graph consists of vertices and edges; weighted graphs attach a cost to each edge. A spanning tree connects every vertex without cycles and has V−1 edges for V vertices. A Minimum Spanning Tree (MST) is a spanning tree with the smallest total edge weight. Prim's algorithm starts from one vertex and repeatedly adds the cheapest edge connecting the current tree to a vertex outside it. Kruskal's algorithm sorts all edges by weight and adds the next cheapest edge only if it does not create a cycle. Union-Find/Disjoint Set Union can efficiently check whether two vertices already belong to the same component.

Related concepts to remember

Both are greedy algorithms. Prim grows one connected tree; Kruskal builds components and joins them. A disconnected graph has a minimum spanning forest rather than one spanning tree. Equal edge weights can allow multiple valid MSTs.

Time and space complexity

Prim: O(V²) with an adjacency matrix or O(E log V) with a priority queue and adjacency list. Kruskal: typically O(E log E), mainly due to sorting.

Likely external viva questions

How many edges are in a spanning tree?

V−1 edges for V vertices.

Prim vs Kruskal?

Prim grows a tree from a starting vertex; Kruskal selects globally sorted edges while avoiding cycles.

Can an MST contain a cycle?

No, a spanning tree is acyclic.

What is a greedy algorithm?

An approach that repeatedly selects the best currently eligible choice.

EXPERIMENT 04

0–1 Knapsack Using Dynamic Programming

Theory and working

The 0–1 Knapsack problem gives items with weights and values and a bag with capacity W. The aim is to maximize total value without exceeding W. Each item must be either selected once or not selected; fractional portions are not allowed. Dynamic Programming stores answers to smaller subproblems. Let dp[i][w] be the maximum value using the first i items with capacity w. If item i is too heavy, copy dp[i−1][w]. Otherwise take the maximum of excluding it and including it: max(dp[i−1][w], value[i] + dp[i−1][w−weight[i]]). The final answer is dp[n][W].

Related concepts to remember

DP is useful when subproblems overlap and an optimal solution can be built from optimal smaller solutions. The table can also be traced backwards to identify the selected items. Fractional knapsack differs because it allows taking part of an item.

Time and space complexity

Time O(nW), space O(nW) for the full table. Space can be reduced to O(W) with a one-dimensional table, processing capacities in descending order.

Likely external viva questions

Why is it called 0–1?

Every item is either taken once or not taken.

Why use DP?

It stores overlapping subproblem results to avoid repeated work.

0–1 vs fractional knapsack?

0–1 items cannot be split; fractional items can be split.

EXPERIMENT 05

N-Queens Using Backtracking

Theory and working

The N-Queens problem places N queens on an N×N chessboard so that no two queens attack each other. Queens attack along rows, columns and diagonals. A common backtracking solution places one queen in each row. For each row, it tries each column and checks whether the position conflicts with any already placed queen. If safe, it proceeds to the next row. If no position works, it removes the previous queen and tries another choice. A complete placement of N queens is a solution.

Related concepts to remember

Two queens share a diagonal when the absolute difference between their row numbers equals the absolute difference between their column numbers. Backtracking prunes invalid partial arrangements instead of exploring every complete board.

Time and space complexity

Worst-case search is exponential; a common upper-bound description is O(N!) with row-by-row placement and column restrictions. Auxiliary space is O(N) for the placement and recursion stack.

Likely external viva questions

What is backtracking?

Build a candidate step by step and undo a choice when it cannot lead to a valid solution.

How is diagonal conflict checked?

The absolute row difference equals the absolute column difference.

Does every N have a solution?

For the standard problem, solutions exist for N=1 and N≥4; N=2 and N=3 have none.

EXPERIMENT 06

Sum of Subsets Using Backtracking

Theory and working

The Sum of Subsets problem finds subsets whose values add up to a target. For each element, the algorithm considers two choices: include it or exclude it. It tracks the current sum and selected elements. If the sum equals the target, a solution is found. If the sum already exceeds the target, a branch can be abandoned when all values are non-negative. Additional pruning can stop a branch if the remaining values cannot reach the target. The pruning rules must match the input assumptions; negative values can make some simple pruning rules invalid.

Related concepts to remember

For n elements, there are 2ⁿ possible subsets because each element has two choices. Backtracking reduces work by abandoning partial choices that cannot succeed, but worst-case exploration can still be exponential.

Time and space complexity

Worst-case time O(2ⁿ); auxiliary space O(n) for recursion and the current subset, excluding stored output.

Likely external viva questions

Why are there 2ⁿ subsets?

Each element is either included or excluded.

What is pruning?

Stopping a branch when it cannot lead to a valid answer.

When is sum-greater-than-target pruning safe?

When values are non-negative, so adding more values cannot reduce the sum.

EXPERIMENT 07

Floyd–Warshall: All-Pairs Shortest Paths

Theory and working

Floyd–Warshall finds shortest-path distances between every pair of vertices in a weighted graph. Initialize a distance matrix with 0 on the diagonal, direct edge weights where edges exist, and infinity where no direct edge exists. Then consider each vertex k as an allowed intermediate vertex. For every pair i,j, update dist[i][j] to min(dist[i][j], dist[i][k] + dist[k][j]). After all intermediate vertices have been considered, the matrix contains all-pairs shortest distances.

Related concepts to remember

It works for directed or undirected graphs and permits negative edge weights, but shortest distances are not well-defined if a reachable negative-weight cycle exists. A negative value on dist[i][i] after processing indicates a negative cycle.

Time and space complexity

Time O(V³), space O(V²) for the matrix.

Likely external viva questions

Why is it dynamic programming?

It improves paths in stages by allowing more intermediate vertices.

Can it handle negative edges?

Yes, but not meaningful shortest distances in the presence of negative-weight cycles.

How detect a negative cycle?

Check whether any diagonal distance dist[i][i] is negative.

Floyd–Warshall vs Dijkstra?

Floyd–Warshall computes all pairs; Dijkstra typically computes from one source and requires non-negative edge weights.

EXPERIMENT 08

Bellman–Ford: Single-Source Shortest Paths

Theory and working

Bellman–Ford computes shortest distances from one source to all other vertices. Set the source distance to 0 and all other distances to infinity. Relax every edge up to V−1 times. Relaxing edge (u,v) with weight w means updating dist[v] when dist[u]+w is smaller. A shortest simple path can have at most V−1 edges, so V−1 rounds are enough when no reachable negative cycle exists. One additional pass checks for further improvements; if any distance can still decrease, a negative-weight cycle is reachable from the source. The algorithm can stop early if an entire pass makes no changes.

Related concepts to remember

Bellman–Ford handles negative edge weights and detects reachable negative cycles. A negative cycle has a total edge weight below zero, so repeatedly traversing it can keep reducing the path cost.

Time and space complexity

Time O(VE), space O(V) for distances, excluding graph storage.

Likely external viva questions

Why V−1 rounds?

A shortest simple path in a graph with V vertices contains at most V−1 edges.

What is relaxation?

Improving a tentative distance when a cheaper path is found.

Bellman–Ford vs Dijkstra?

Bellman–Ford supports negative edges and detects reachable negative cycles; Dijkstra is generally faster but requires non-negative weights.

EXPERIMENT 09

Naïve String Matching

Theory and working

String matching locates a pattern inside a larger text. The naïve algorithm aligns the pattern at every possible starting position and compares characters from left to right. If every character matches, it reports that position. If a mismatch occurs, it shifts the pattern one position and tries again. For text length n and pattern length m, possible starting positions run from 0 through n−m when m≤n. It is simple and requires no preprocessing, but may repeat many comparisons.

Related concepts to remember

The text is the full string; the pattern is the smaller string being searched. Programming languages commonly use zero-based indexes. If the pattern is longer than the text, no alignment is possible. More advanced methods include KMP and Rabin–Karp.

Time and space complexity

Worst-case time O((n−m+1)m), commonly written O(nm); extra space O(1), excluding match positions.

Likely external viva questions

What is the naïve method?

Try each possible alignment and compare characters one by one.

What if pattern is longer than text?

No match is possible.

Name a more advanced algorithm.

KMP or Rabin–Karp.

EXPERIMENT 10

Longest Common Subsequence (LCS)

Theory and working

The Longest Common Subsequence problem finds the longest sequence appearing in two strings in the same relative order; characters need not be adjacent. For example, ACE is a subsequence of ABCDE. It is different from a substring, which must be contiguous. Let dp[i][j] be the LCS length for the first i characters of X and first j characters of Y. The first row and column are zero because an empty string has no common characters. If the current characters match, dp[i][j]=dp[i−1][j−1]+1. Otherwise, dp[i][j]=max(dp[i−1][j], dp[i][j−1]). The final cell gives the length. Backtracking through the table can recover an actual subsequence.

Related concepts to remember

LCS is a dynamic programming problem because answers for prefixes of the strings are reused. It is useful in file comparison, text similarity and biological sequence comparison.

Time and space complexity

For strings of lengths m and n, time is O(mn) and full-table space is O(mn). If only the length is needed, space can be reduced to O(min(m,n)) with rolling rows.

Likely external viva questions

What is a subsequence?

A sequence made by deleting zero or more characters without changing the order of remaining characters.

LCS vs longest common substring?

A subsequence can have gaps; a substring must be contiguous.

Why initialize first row and column to zero?

An empty string has an LCS length of zero with any string.

Where is LCS used?

Version comparison, text similarity and sequence analysis.

REVISION

General ADSA Viva Questions

These fundamentals may be asked with any practical.

What is an algorithm?

A finite, ordered set of clear steps for solving a problem.

What is a data structure?

A way of organizing data to support efficient access and modification.

What is time complexity?

How an algorithm's running time grows with input size.

What is space complexity?

How the memory requirement grows with input size.

What does Big-O notation describe?

An asymptotic upper bound on growth, commonly used to discuss worst-case efficiency.

What is recursion?

A function calling itself on smaller cases until a base case stops the calls.

What is a base case?

The stopping condition in a recursive algorithm.

What is dynamic programming?

A method that stores results of overlapping subproblems to avoid repeated work.

What is backtracking?

A method that explores choices and undoes a choice when it cannot lead to a valid solution.

What is a greedy algorithm?

An approach that repeatedly selects the best eligible local choice; it is optimal only for suitable problems.

What is a graph?

A structure of vertices connected by edges; graphs may be directed or undirected and weighted or unweighted.

Adjacency matrix vs adjacency list?

A matrix uses O(V²) space; an adjacency list typically uses O(V+E) space.

What is a tree?

A connected, acyclic graph.

What do V and E mean?

V is the number of vertices; E is the number of edges.

What is the difference between worst and average case?

Worst case is the maximum work for inputs of a given size; average case is expected work under an assumed input distribution.

Why analyze algorithms?

To compare efficiency and estimate performance as inputs grow.

QUICK REFERENCE

Complexity Quick Guide

  • O(1): constant growth.
  • O(log n): logarithmic growth, often when the search space is repeatedly reduced.
  • O(n): linear; one pass through n elements.
  • O(n log n): common in efficient comparison sorting and some graph algorithms.
  • O(n²): quadratic; often two nested loops.
  • O(n³): cubic; three nested loops, as in Floyd–Warshall.
  • O(2ⁿ) or O(n!): exponential/factorial growth, common in combinatorial search.

Symbols: n is input size; h is tree height; V is number of vertices; E is number of edges.

Time complexity describes work performed. Space complexity describes memory required. Big-O describes an asymptotic upper bound and is commonly used to express worst-case growth.
